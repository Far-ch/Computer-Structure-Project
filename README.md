# Processor Extensions in Digital

Final project for Computer Structure and Microprocessor, Sharif University of Technology (Dr. Saeed Bagheri Shouraki).

We extended the pre-designed processor in the [Digital](https://github.com/hneemann/Digital) logic simulator, using assembly programs and hardware changes.

## Projects

1. **LED matrix font:** replaced the default font of the LED matrix display.
2. **LED chaser:** modified the processor so its output runs as a back-and-forth LED chaser.
3. **Keyboard to LED matrix:** added a keyboard input; letters swap case, digits pass through unchanged, and the result is shown on the LED matrix.

## Run

Open the `.asm` file in Digital, load the assembled program, and start the simulation.
